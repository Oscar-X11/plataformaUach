## 3. Docente: permisos y validaciones

**Permisos.** El docente solo actúa en sus propias clases. Las actividades que pone como requisito y los temas del material deben ser de la misma clase, y no tiene acceso a usuarios, catálogo ni reportes.

**Validaciones nuevas.** Las reglas viven en el backend; el frontend las repite para avisar antes de enviar.

| Dónde | Qué se evita |
| --- | --- |
| Tareas | Fecha de entrega en el pasado (todos quedarían con la tarea vencida); apertura posterior a la entrega |
| Rúbricas | Dos niveles con los mismos puntos o el mismo nombre; criterios repetidos; criterio cuyo mejor nivel vale 0. El editor marca cada problema, avisa que la rúbrica se congela al calificar y confirma si cambian los puntos de la tarea |
| Cuestionarios | Publicar uno que vale 0 puntos o cuyo cierre ya pasó; guardar un borrador con cierre en el pasado. Errores por pregunta (opciones vacías o repetidas, sin respuesta correcta) y avisos (se califica a mano, vale 0, todas las opciones correctas). Publicar pide confirmación con alumnos, puntos, cierre y preguntas a calificar a mano |
| Encuestas | Ya no aceptan tiempo límite |
| Pesos | Confirmación antes de recalcular la calificación final de todo el grupo |
| Periodo cerrado | No se crean tareas ni cuestionarios, ni se cambian rúbricas, puntos o pesos |

## 6. Revisión de posibles errores

Se revisó el diff completo. Se corrigieron dos importaciones sin uso. Quedan estos puntos, ninguno bloqueante:

| Punto | Riesgo | Sugerencia |
| --- | --- | --- |
| Un borrador de cuestionario cuyo cierre ya pasó no se puede guardar desde el editor, ni siquiera para cambiar el título, hasta corregir la fecha. El backend sí lo permitiría si la fecha no cambia | Bajo: obliga a corregir algo que de todos modos impide publicar | Dejarlo así |
| El formulario de tareas compara la fecha al minuto. Una tarea creada por API con segundos se toma como «fecha cambiada» | Muy bajo: solo si esa fecha ya pasó, y el aviso es correcto | Ninguna |
| Las rúbricas guardadas antes con niveles de igual puntaje ya no pasan la validación al editarlas | Bajo: el editor señala el problema al abrirlas | Revisar las rúbricas existentes si las hay |
| El reporte calcula el riesgo curso por curso (servidor de 4 GB) | Medio con muchos cursos y sin filtros | Filtrar por periodo o carrera; si se vuelve lento, agregar los datos en SQL |
